# Gmail送信用テンプレート

このテンプレートは、グルメ専用Gmailへ素材を送るときに毎回コピペして使う。

## 件名

```text
[グルメCanva] 店舗名
```

例:

```text
[グルメCanva] 焼肉しょうちゃん天満
```

## 本文 — 推奨版

```text
店舗名：
コース：
エリア：

料理：
・
・
・

メモ：
・
・
```

### 入力ルール

- 店舗名：必須
- コース：分かる場合のみ
- エリア：分かる場合のみ
- 料理：分かる範囲で、できれば提供順
- メモ：実際に食べて感じたこと / 特に推したい料理 / PR条件など
- 写真：メールに添付。原則20枚以内
- 分からない項目は空欄のままでよい

## 本文 — 最短版

時間がないときはこれだけでもよい。

```text
店舗名：
コース：

メモ：
・
```

写真を添付し、料理名や店舗情報はChatGPT側でWeb調査して補完する。

## 重要

味の感想は、実際に感じた内容だけメモに書く。

例:

```text
メモ：
・タンが特に美味しかった
・肉うどんはボリュームたっぷり
・ハラミを強く推したい
```

これらはユーザー自身の実食情報として投稿コピーに利用できる。

一方、分からないことを無理に書く必要はない。
