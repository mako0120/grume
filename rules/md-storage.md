# Markdown保管ルール

## 保存場所

```text
posts/YYYY/MM/YYYY-MM-DD_店舗名/
```

例:

```text
posts/2026/09/2026-09-28_焼肉しょうちゃん天満/
  post.md
  record.md
```

## post.md

投稿そのものの完成仕様。

含める:

- 基本情報
- Web調査メモ
- 表紙
- 各ページ
- 写真対応
- 料理名
- コピー
- 注意事項

## record.md

制作ログ。

含める:

- 受信日
- 店舗名
- コース
- ステータス
- Canva URL
- 使用テンプレート
- 要確認事項
- 完成日時

## INDEX

新規案件完成後:

```text
posts/INDEX.md
```

へ1行追加する。

## ファイル名

日本語店舗名をそのまま使用可能。

ファイル内にメールアドレスなど不要な個人情報は保存しない。
