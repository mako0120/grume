# Gmail入力ルール

## 推奨件名

```text
[グルメCanva] 店舗名
```

例:

```text
[グルメCanva] 焼肉しょうちゃん天満
```

## 本文

最低限:

```text
店舗名：〇〇
```

推奨:

```text
店舗名：〇〇
コース：〇〇
エリア：〇〇

料理：
・料理A
・料理B
・料理C

メモ：
・特に推したい料理
・実際に感じたこと
・PR条件など
```

## 写真

- 1〜20枚程度
- 送信順は必ずしも投稿順でなくてよい
- コース順が本文にある場合はAI側で並べ替える
- 写真から料理名を断定できない場合は本文の料理一覧を照合する

## 対象外

以下は自動処理しない。

- `[グルメCanva]` がない一般メール
- 写真がない依頼
- 店舗名が一切分からない依頼
- すでに処理済みのメール

## 重複防止

処理済みメールを再処理しない。

同じ店舗でも、新しいメールで新しい撮影素材が届いた場合は別案件として扱う。
