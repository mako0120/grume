# グルメCanva投稿 制作ルール

## 基本

サイズ:

```text
1080 × 1350 px
4:5
```

基準デザイン:

- 焼肉 城と七宝 — `DAHRTs0jdPw`
- 蟹かに城 — `DAHQmZ-GP3I`

## デザイン

原則として以下を変更しない。

- フォント
- 文字の並び
- 基本レイアウト
- 文字位置
- ページ構成
- 視線誘導
- デザイン全体のトーン

**中身だけ差し替える。**

差し替え対象:

- 店名
- 最寄駅
- エリア
- 料理名
- 投稿コピー
- 写真
- 必要なPR情報

## ページ構成

基本:

1. 表紙
2. 店舗 / 店内導入
3. ドリンクまたは導入
4. 料理
5. 料理
6. …
7. 最終ページ / 締め

料理順・コース順がユーザーから与えられている場合、**その順番を最優先**する。

同じ料理の:

- 皿写真
- 焼いている写真
- 箸上げ
- 断面 / アップ

はできるだけ近接させる。

## 表紙

基本要素:

```text
📍店舗名
短い惹き文句
\強いフック/
最寄駅
大阪
```

表紙は一目で内容が分かること。

## コピー

文章:

- 短文
- 話し言葉
- 絵文字あり
- 写真主役
- Instagramらしいテンション
- 同じ言い回しを連発しない

強い表現例:

- 優勝すぎる
- ビジュやばすぎる
- 反則級
- ご飯泥棒
- 止まらん
- たまらん
- えぐい
- 最高すぎる
- 主役級
- 幸せ爆発

### 強い表現ルール

同じ強い表現は **1投稿につき原則1回まで**。

「最高」「優勝」「やばい」など意味が近い語も連発しない。

## 事実確認

絶対に捏造しない。

写真だけでは分からないもの:

- 味
- 産地
- 正確な部位
- 調理方法
- 値段
- 店舗の人気度
- 営業時間
- 定休日

は、ユーザー提供情報またはWebで確認できた情報だけ使う。

料理名の確信が低い場合:

```text
要確認
```

として扱う。

## Web調査

優先順位:

1. 店舗公式サイト
2. 公式Instagram
3. Google Maps等
4. 食べログ等
5. その他信頼できる店舗情報

営業時間 / 定休日 / 価格など変動する情報を投稿に入れる場合は最新情報を確認する。

## 完成前確認

- 店名は正しいか
- 写真と料理名は一致しているか
- コース順が守られているか
- コピーが写真と一致しているか
- 強い表現が重複していないか
- 未確認事項を断定していないか
- 文字がはみ出していないか
- Canvaテンプレートの見た目を壊していないか
