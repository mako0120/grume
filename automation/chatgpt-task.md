# ChatGPT Automation 実行指示

## 目的

Gmailに届いたグルメ制作依頼を検知し、ユーザーがこのチャットを開かなくても、Web調査・Markdown作成・Canva制作・保存・GitHub記録まで完了させる。

## 対象メール

以下を満たすものを処理対象とする。

- 件名に `[グルメCanva]` を含む
- 画像が添付されている
- まだ処理済みでない
- 店舗名を件名または本文から取得できる

## 実行順

1. Gmailから対象メールを取得
2. 店舗名 / コース / エリア / 料理名 / 料理順 / メモを抽出
3. 添付写真を確認
4. 写真を外観 / 店内 / ドリンク / 料理 / 焼き工程 / アップ / 締め等に分類
5. Web検索で店舗を調査
6. 一次情報を優先して事実確認
7. コース順がある場合はそれを最優先して写真順を決める
8. `rules/gourmet-canva.md` に沿って投稿コピーを作成
9. `templates/post-template.md` 形式でMarkdownを作成
10. 適切なCanva基準テンプレートをコピー
11. 既存デザインのフォント・レイアウト・ページ構成を維持して写真と文章を差し替える
12. 全ページの写真と文章の対応を確認
13. Canvaを保存
14. 完成MDをGitHub `posts/` に保存
15. 制作記録 `record.md` を保存
16. `posts/INDEX.md` に新規投稿を追記
17. Gmail側を処理済みにする
18. 完成Canva URLと要確認事項を元メールへ返信

## 重要ルール

- 未確認の味・価格・営業時間・料理名を断定しない
- 写真で特定できない料理は無理に断定しない
- 公式サイト / 公式Instagramを優先
- Google / 食べログ等は補助情報として使用
- 強い表現を同じ投稿内で繰り返さない
- 写真と文章が不一致のまま完成扱いにしない
- Canva保存前にページ全体を確認する
- 同じGmailを二重処理しない

## 完成条件

以下をすべて満たした場合のみ完成扱い。

- Web調査済み
- 投稿MD作成済み
- 写真順確定
- Canva制作済み
- Canva保存済み
- GitHubへMD保存済み
- Gmail返信済み

不明点がある場合は `要確認` を付け、推測を事実として書かない。
